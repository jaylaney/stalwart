candidate with the zero-access contracts intact.

workspace and crates in dependency order, review each task, then qualify the assembled
branch and its product binary before handoff.

and gate tools, and GitHub Actions.

  worktree and an accepted task commit before the next writer starts.
- [ ] Log the task, input/output SHAs, actual model and effort, paths, command results,

  Keep sanitized logs there or link their local paths. Leave secrets out of all records.
